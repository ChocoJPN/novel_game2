# novel_game

Ren'Py エンジンで制作中の学園青春ノベルゲームプロジェクトです。

---

## 📖 あらすじ・概要

『高校生活を振り返って』というレポートを白紙で提出した主人公・**藤沢 透**は、現国教師の**愛川 文乃**から「罰」として、部員ゼロで廃部寸前の**文芸部**を再建するよう命じられる。
名前のない教室で出会った少女・**鎌倉 詩乃**とともに、部員集めの日々が始まる——。

## ✨ 特徴：微細なデザイン変化による好感度システム

本作では、画面上に無機質な数字を出さず、**視覚的なデザイン変化と色彩の温度感**によってキャラクターとの距離感を静かに伝えるUIシステム（[`game/affection_ui.rpy`](game/affection_ui.rpy)）を採用しています。

### 1. 状態に応じて表情を変える「好感度バー」
画面左上（立ち絵やテキストと重ならない位置）に、数値を持たない専用の好感度ゲージが表示されます。

* **初期状態（好感度 `0`）**: クールな青色のゲージとシンプルなフレーム
* **好感度プラス（`+1` 〜 `+100`）**:
  * ゲージの色が **ラベンダー → 桜ピンク → 温かいコーラルピンク** へと変化しながら伸びていきます。
  * フレームの周囲に **若いツタと葉（Lv.1）→ 花の蕾と小花（Lv.2）→ 満開の花々と光の粒（Lv.3）** が段階的に咲き誇ります。
* **好感度マイナス（`-1` 〜 `-100`）**:
  * ゲージの色が **冷たい濃紺・群青** へ沈み、ゲージ内部にも亀裂が入ります。
  * フレームに **わずかな亀裂（Lv.-1）→ 枝分かれするヒビ（Lv.-2）→ 深い破損（Lv.-3）** が走ります。

### 2. 名前の文字色（フォントカラー）の連続グラデーション
好感度が変化するにつれて、会話ウィンドウおよびバー上部のキャラクター名が **1ポイント単位で滑らかに色変化（RGB線形補間）** します。

* **鎌倉 詩乃 (`k`)**: 氷のような濃紺 (`#2b4478`) ⇄ 冷たい青 (`#5b86d6`) ⇄ 柔らかな桜色 (`#df7da2`) ⇄ 温かい茜・コーラルレッド (`#ff625c`)
* **真鶴 千景 (`m`)**: 凍てつく群青 (`#293d70`) ⇄ クールな青 (`#5c7ad6`) ⇄ 華やかなマゼンタ (`#eb73be`) ⇄ ウォームコーラル (`#ff7b54`)

## 🛠️ シナリオ（`script.rpy`）での好感度操作リファレンス

[`game/script.rpy`](game/script.rpy) 内で以下のコードを1行記述するだけで、好感度バーの表示や数値の増減を行えます。

```renpy
# ヒロインが名乗ったタイミング等で好感度バーを解禁（表示開始）する
$ unlock_affection("k")    # 鎌倉詩乃のバーを解禁
$ unlock_affection("m")    # 真鶴千景のバーを解禁

# 好感度を増減する（バーの伸縮・装飾変化・名前の色変化が自動で反映されます）
$ add_affection("k", 15)   # 鎌倉詩乃の好感度を +15
$ add_affection("k", -20)  # 鎌倉詩乃の好感度を -20
$ add_affection("m", 25)   # 真鶴千景の好感度を +25

# 好感度を特定の値（-100 〜 100）に直接設定する
$ set_affection("k", 80)

# 好感度バーを一時的に隠す／再表示する
$ show_affection_bar = False
$ show_affection_bar = True
```

> **💡 自動ターゲット切り替え**:
> 複数のヒロインのバーが解禁されている場合、発話したヒロイン（`k` または `m`）に合わせて左上の好感度バーの表示対象が自動的に切り替わります。

## 🧪 開発用デバッグパネル

ゲームプレイ中にキーボードの **`F8` キー** を押すと、画面右上に開発用のテストパネルが開閉します。
* 対象ヒロイン（詩乃／千景）の解禁・切り替え
* 各段階（`ひびLv3(-85)` 〜 `初期(0)` 〜 `満開Lv3(+85)`）のワンクリックプレビュー
* `-10` / `-5` / `+5` / `+10` の微調整テスト
* 現在の内部数値とカラーコード（`#RRGGBB`）の確認

## 🚀 起動方法

1. [Ren'Py SDK](https://www.renpy.org/)（8.x 推奨）をインストールします。
2. Ren'Py ランチャーを起動し、プロジェクト一覧から **`novel_game`** を選択します。
3. **「プロジェクトを起動 (Launch Project)」** をクリックしてゲームを開始します。
   * スクリプト編集後は、ゲーム画面上で **`Shift + R`** を押すとリアルタイムにリロードされます。
